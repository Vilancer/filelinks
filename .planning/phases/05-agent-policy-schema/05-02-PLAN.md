Create `stagedClassifier.ts` with:

```ts
export interface StagedLinkCoverage {
  entry: FileLinkEntry;
  triggerMatched: boolean;
  affectMatched: boolean;
  triggerPaths: string[];
  affectPaths: string[];
  missingAffected: AffectedFile[];
}

export function classifyStagedLinks(
  stagedPaths: string[],
  links: FileLinkEntry[],
): StagedLinkCoverage[];
```

Implementation rules (D-02, D-03):

1. Iterate **every** `entry` in `links` (stable order).
2. `triggerPaths` = staged paths where `minimatch(p, entry.trigger)`; `triggerMatched = triggerPaths.length > 0`.
3. For each affect, if `stagedCoversAffected(stagedPaths, aff.file, entry.linkType)`, add each staged path that satisfies (minimatch OR dir-prefix per existing helper) to `affectPaths`; dedupe with `Set` or filter.
4. `affectMatched = affectPaths.length > 0`.
5. **In play** = `triggerMatched || affectMatched`.
6. If in play: `missingAffected` = affects where `!stagedCoversAffected(...)` (same loop as `matchStagedLinks`).
7. If not in play: `missingAffected = []`, booleans false, path arrays empty.

Export from `packages/core/src/index.ts`: `export * from './lib/stagedClassifier'`.
</action>
