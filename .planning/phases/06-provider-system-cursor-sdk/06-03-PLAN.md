Implement **`run(input: AgentRunInput)`**:

1. `validateCredentials` then read `config` from input (already **`ResolvedAgentConfig`**).

2. Build **`Agent.create`** options:
   - `apiKey` explicit
   - `model: { id: config.model }`
   - If `config.runtime === 'local'`: `local: { cwd: config.local!.cwd, settingSources: [] }` — **do not** pass `cloud`
   - If `config.runtime === 'cloud'`: `cloud: { repos: config.cloud!.repos }` — **do not** pass `local`

3. `const run = await agent.send(input.prompt)`; `const result = await run.wait()`; **dispose** agent in `finally` (or `await using` if TS supports).

4. If **`result.status === 'error'`** → throw **`AgentRunFailedError`** with `run.id`.

5. On catch: if error is **`CursorAgentError`** (import from SDK), throw **`AgentStartupError`** with `isRetryable` in details; rethrow `FilelinksError` subclasses; wrap unknown.

6. Return `{ status: 'finished', runId: result.id, resultText: extract final assistant text if available else undefined }`.

**Tests** (mocked SDK):

- local create options include `cwd: '/tmp/repo'`
- cloud create options include `repos: ['org/repo']`
- `result.status === 'error'` → `AGENT_RUN_FAILED`
- thrown `CursorAgentError` → `AGENT_STARTUP_FAILED`

Update **`registerBuiltInProviders()`** in `providers/index.ts` to `registerAgentProvider(cursorAgentProvider)`.

Ensure `packages/core/src/index.ts` imports `./lib/providers` (or calls `registerBuiltInProviders`) so Cursor is registered when core loads.
</action>
