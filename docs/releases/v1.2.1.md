# filelinks v1.2.1

Release date: TBD (set on publish)
Patch release on top of [v1.2.0](v1.2.0.md).

## Fixes

- **Security (dependency):** `@vilancer/filelinks` no longer depends on `fast-glob`, which pulled in `braces` <= 3.0.3
  (npm audit: high, stack exhaustion on deeply nested brace patterns) through `micromatch`. The `filelinks add`
  wizard's path list (used outside a git work tree) now uses `tinyglobby`. No published filelinks package depends on
  `braces` or `micromatch` anymore.

## Notes

- No behaviour changes. `@vilancer/filelinks-core` and `@vilancer/filelinks-git-hook` are re-released at 1.2.1 so
  all three packages keep the same version.

## Post-merge release commands (run on `main`)

```bash
git switch main && git pull --ff-only
pnpm exec nx run-many -t build --projects=core,cli,git-hook --skip-nx-cache
git tag -a v1.2.1 -m "filelinks v1.2.1"
git push origin v1.2.1
pnpm --filter @vilancer/filelinks-core publish --access public
pnpm --filter @vilancer/filelinks publish --access public
pnpm --filter @vilancer/filelinks-git-hook publish --access public
gh release create v1.2.1 --title "filelinks v1.2.1" --notes-file docs/releases/v1.2.1.md
```
